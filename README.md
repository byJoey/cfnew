# CFnew 精简内核

内核 37,806 字节，较原完整版本减少约 92%。Worker 负责代理转发和 KV 配置。页面、优选列表处理与订阅生成由独立面板提供。

**面板：[https://cfnew.xy.kg/](https://cfnew.xy.kg/)**

填自己的 **Worker 域名和 UUID 或自定义路径** 即可接入。面板服务器提供页面与订阅，节点流量仍直接连接你的 Worker。

## 版本与更新

当前面板与配套内核版本：**2026.10.17.2**。

版本一致时不显示提示。不一致或旧内核未标版本时，才显示双方版本、更新内容和下载入口。上传新版 `_worker.js` 或 `pages.zip`，保留原来的 `u` 和 `C/c` 绑定，再刷新面板即可。

本次更新：

- 新增 **Free CPU 保护**，默认关闭；面板保存后对新连接生效。
- 保留 WS/XHTTP，单连接上下载合计最多 **384 KiB 或 96 个数据块**，超过主动断开，让客户端重新连接。当前下载、视频或长连接可能中断，不保证自动续传。
- 预算根据实测校准，减少重复鉴权计算和拷贝；Worker 无法读取实时 CPU 余量，因此不保证所有免费账号零超限。设置 Worker 变量 `freeCpu=yes` 或 `FREE_CPU=yes` 也可开启，KV 配置优先。
- 旧内核不支持开关，更新时保留原 `u` 和 `C/c` 绑定。


## 部署

1. **Pages 部署**：下载 [`pages.zip`](./pages.zip)，在 Cloudflare Pages 的直接上传页面上传这个压缩包。包的根目录只有 `_worker.js`。**Workers 部署**：下载 [`_worker.js`](./_worker.js) 后上传。
2. 在 Worker 环境变量中设置 `u` 为自己的 UUID，`U` 也支持。
3. 创建 KV 命名空间，绑定名称填写 `C` 或 `c`。没有 KV 可以生成订阅，保存配置需要 KV。
4. 给 Worker 绑定可用域名，打开上面的面板，填写域名和同一个 UUID，也可以填写 `d` 设置的自定义路径。
5. 在面板设置协议、优选地址等，复制面板生成的订阅地址到客户端。

Worker 首页返回 `hello`。Worker 原来的页面和 `/sub` 路径已经移出，订阅必须使用面板生成的新地址。

在入口页选择已保存的节点后，可点击“删除所选”。记录只从当前浏览器删除，Worker 配置保持不变。

## 自定义路径登录

例如 Worker 的 `d` 设置为 `/Admin/Panel`，面板第二项填 `/Admin/Panel` 或 `Admin/Panel` 即可。多级路径、中文路径和前后斜杠均支持，大小写必须一致。`d` 是配置入口，`tp` 是代理传输设置，两者用途不同。

自定义路径登录需要本分支最新版内核，已鉴权后面板自动读取代理 UUID。修改 `d` 后，已打开的面板和已复制的订阅仍可用。旧版内核仍支持 UUID 登录。

## 保留的功能

- 两种 WebSocket 协议、XHTTP（HTTP/2，stream-one）、DNS 转发。
- SOCKS5、HTTP、HTTPS 出站与原有回退配置。
- KV 配置读取、保存与优选地址增删接口。
- 面板提供优选域名、默认优选 IPv4/IPv6、运营商筛选、手填地址、在线列表和原客户端订阅格式。
- 主分支已有的家宽链式订阅开关。

优选域名和优选 IP 默认开启。手填列表每行一个，也兼容英文逗号，例如 `104.16.1.1:443#备注,[2606:4700::1111]:8443#IPv6`。设置在线列表 `yxURL` 后，需开启“仓库优选”来源开关；有手填列表时优先使用手填内容。

优选输入框支持多行粘贴和拖动高度。大量手填地址请升级本分支最新版内核；旧版内核的字段上限较小。最新版优选列表上限为 262144 字符，完整配置请求上限 1 MiB；超过时可改用列表 URL。

## 在线优选

在面板获取在线列表或填入 IP、域名后，点击测试，选择结果并覆盖或追加保存。IPv4、IPv6、域名及显式端口均支持；订阅会保留填写的端口。

检测由独立面板服务器发起，使用你的 Worker 域名作为 Host/SNI。显示的延迟是面板服务器视角，客户端实际延迟以客户端测速为准。

本分支提供精简内核和说明，独立面板源码见 [cfnew-panel](https://github.com/byJoey/cfnew-panel)。原完整版本仍在 `main`，本分支不会覆盖它。
