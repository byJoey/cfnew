# CFnew 精简内核 2026.10.17.2

这是 **精简内核版**，来自默认分支 `core-only`。旧完整版仍在 `main`，旧版下载保留在 [v3.1](https://github.com/byJoey/cfnew/releases/tag/v3.1)。

**[部署和迁移说明](https://github.com/byJoey/cfnew/blob/core-only/README.md) · [完整变量表](https://github.com/byJoey/cfnew/blob/core-only/docs/variables.md) · [视频教程](https://www.youtube.com/watch?v=EfhHV62CuEU&t=2s) · [打开面板](https://cfnew.xy.kg/)**

## 下载哪个文件

Windows、macOS、Linux 都用同一份，按 Cloudflare 部署方式选择。

| 文件 | 用途 |
| --- | --- |
| `Pages.zip` | Cloudflare Pages 直接上传。包根目录只有 `_worker.js`，不用解压。 |
| `_worker.js` | Cloudflare Workers 编辑器中完整替换代码，保留 ES Module 格式。 |
| `SHA256SUMS.txt` | 上述两份文件的 SHA-256 校验值。 |

GitHub 自动附带的 `Source code` 是整个源码仓库，不能直接作为 Pages 部署包。仓库的 `pages.zip` 与本发行的 `Pages.zip` 字节一致。

## 内核与面板

- 核心 **37,806 字节**，负责代理转发、DNS 转发与 KV 配置接口。
- 管理页面、优选列表处理、在线检测和订阅生成由独立面板提供。
- 保留 VLESS WS、Trojan WS、VLESS XHTTP（HTTP/2、`stream-one`），支持 SOCKS5 / HTTP / HTTPS 出站。精简内核不提供 Shadowsocks 入站与通用 UDP 转发。
- 节点流量仍直接连接自己的 Worker，不经过面板服务器。独立面板源码见 [cfnew-panel](https://github.com/byJoey/cfnew-panel)。

## 本版新增：Free CPU 保护

- 默认关闭，可在面板开启并保存，或设置 Worker 变量 `freeCpu=yes` / `FREE_CPU=yes`。KV 配置优先，对新连接生效。
- 上下载共用 **384 KiB / 96 个数据块**预算，超出任一项就主动断开；新连接重新计算，保留原 WS / XHTTP 协议。
- 减少重复鉴权计算与不必要拷贝。预算经过边缘测试校准，但 Worker 没有实时 CPU 余量接口，**不保证免费账号零超限**。
- 当前下载、视频或长连接可能中断，客户端需要自行重连，不保证自动续传。旧核心需更新后才能使用开关。

本次正式发行还补齐了部署步骤、全部配置字段和别名、配置优先级、API、旧版迁移与文件校验说明；代理核心与已发布的 `2026.10.17.2` 版本一致。

## 部署

1. Pages 上传 `Pages.zip`，或 Workers 粘贴 `_worker.js` 完整代码并部署。
2. 添加文本变量 **`u`**，填自己的 UUID；大写 `U` 也支持。
3. 需要在线保存设置时，绑定自己的 KV，名称填 **`C` 或 `c`**。只添加同名文本变量不能代替 KV 绑定。
4. 兼容日期设置为 **`2026-01-20`**，更改变量、绑定或日期后重新部署。Pages 请确认设置在生产环境。
5. 绑定可用域名，打开 [面板](https://cfnew.xy.kg/)，填写域名和 UUID，也可使用 `d` 设置的自定义路径登录。
6. 保存配置并复制面板生成的订阅到客户端。未绑定 KV 仍可生成订阅，不能在线保存。

Worker 首页显示 `hello` 是正常现象。面板与内核版本一致时不显示升级提示。

## 旧版迁移与回退

- 升级前备份原代码，保留原 UUID、KV 绑定和域名；上传新版不会主动清空 KV。
- **旧 Worker `/UUID/sub` / `/sub` 地址需要换成面板生成的新订阅。** 不能只更新代码、继续沿用旧订阅地址。
- XHTTP 请用 `stream-one`，不要改成 `packet-up` 或 `stream-up`。sing-box 使用 1.12 及以上版本。
- Surge 用户需开启 `et=yes`，当前该格式只输出 Trojan。Clash / sing-box / Loon / QuanX 的 VLESS 节点使用 WS，请保留 `ev=yes`；实际 XHTTP 使用支持它的客户端导入 Base64 / VLESS 分享链接。
- 环境变量修改后若不生效，检查 KV 是否保存了同名配置；优先级是 KV > 环境变量 > 默认值。
- 需要回退时重新上传备份的旧版代码，保留原绑定，并恢复对应版本的订阅入口。

## 校验文件

macOS：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Linux：

```bash
sha256sum -c SHA256SUMS.txt
```

Windows PowerShell：

```powershell
Get-FileHash .\Pages.zip -Algorithm SHA256
Get-FileHash .\_worker.js -Algorithm SHA256
```

Windows 将输出与 `SHA256SUMS.txt` 中对应文件的值比较即可。
